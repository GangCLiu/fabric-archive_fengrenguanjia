# 项目需求文档

## 项目名称
**布料档案管家** (Fabric Archive)

## 1. 项目背景
用户是一名缝纫爱好者，经常从淘宝、小红书购买布料。由于布料数量达到几百块，需要一个系统来：
- 自动识别订单信息，减少手动录入
- 建立布料档案库，方便查找和管理
- 关联成衣作品，记录创作历程

## 2. 目标用户
- **主要用户**：项目所有者本人
- **使用场景**：
  - 购买新布料时，快速录入订单信息
  - 准备做衣服时，查找合适的布料
  - 完成作品后，记录成衣并与布料关联
  - 定期备份数据到GitHub

## 3. 功能需求

### 3.1 核心功能（必须有）

#### 1) 订单识别录入
- 上传订单截图（淘宝/小红书）
- 自动OCR识别以下信息：
  - 布料名称/描述
  - 长度（米）
  - 宽度（幅宽，如110cm、140cm）
  - 卖家店铺名
  - 价格（元）
  - 提取布料预览图片
- 显示识别结果，允许手动修正
- 一键保存到布料库

#### 2) 布料档案管理
- 布料列表展示（缩略图+关键信息）
- 布料详情页（完整信息+大图）
- 搜索功能（按名称、店铺、面料类型）
- 筛选功能（按幅宽、价格区间、购买时间）
- 编辑/删除布料记录

#### 3) 成衣作品关联
- 在布料详情页添加成衣记录
- 成衣信息：照片、制作日期、作品名称（可选）、备注
- 一块布料可关联多个成衣作品
- 成衣时间线展示

#### 4) 数据备份
- 一键导出所有数据（JSON格式）
- 自动推送备份到GitHub私有仓库
- 支持从备份恢复

### 3.2 加分功能（后续迭代）
1. 布料统计报表（总花费、各店铺购买量、使用转化率）
2. 布料类型自动分类（棉麻、丝绸、毛呢等）
3. 使用提醒（购买超过X年未使用的布料）
4. 成衣教程链接关联

### 3.3 暂时不需要
1. 多用户支持
2. 社交分享功能
3. 在线购买链接

## 4. 技术要求

### 4.1 数据存储
- **本地SQLite数据库**：存储所有结构化数据
- **本地文件系统**：存储原始订单截图、布料图片、成衣照片
- **文件夹结构**：
  ```
  data/
  ├── fabric_archive.db      # SQLite数据库
  ├── order_images/          # 原始订单截图
  ├── fabric_images/         # 提取的布料图片
  └── garment_images/        # 成衣照片
  ```

### 4.2 用户系统
- 不需要登录/账号系统
- 单用户本地使用

### 4.3 设备平台
- **响应式Web应用**：手机浏览器 + 电脑浏览器都能用
- **本地运行**：数据存储在本地，保护隐私

### 4.4 OCR方案
- **PaddleOCR**：中文识别效果好，开源免费
- 备选：EasyOCR 或 调用云端API（百度/腾讯OCR）

## 5. 界面要求

### 主界面（布料列表）
- 网格/列表切换视图
- 搜索栏置顶
- 筛选器侧边栏（电脑）/下拉（手机）
- "新增布料"悬浮按钮

### 布料详情页
- 大图展示布料
- 基本信息卡片
- 成衣作品时间线
- "添加成衣"按钮

### 新增布料流程
1. 点击"新增" → 上传订单图片
2. 显示OCR识别进度
3. 展示识别结果表单（可编辑）
4. 确认保存

- [ ] 能搜索和筛选布料
- [ ] 能导出数据并推送到GitHub

- [ ] 界面简洁直观，无需教程即可使用
