- [ ] 创建 .gitignore（排除数据文件）

### 2.2 数据库设计
- [ ] 设计布料表 (fabrics)
- [ ] 设计成衣表 (garments)
- [ ] 创建数据库初始化脚本
- [ ] 测试数据库连接

**数据库结构**：
```sql
fabrics:
- id (主键)
- name (布料名称)
- length (长度)
- width (幅宽)
- shop (店铺名)
- price (价格)
- image_path (布料图片路径)
- order_image_path (订单截图路径)
- created_at (录入时间)

garments:
- id (主键)
- fabric_id (外键，关联fabrics)
- name (作品名称)
- image_path (成衣照片路径)
- made_date (制作日期)
- notes (备注)
```
